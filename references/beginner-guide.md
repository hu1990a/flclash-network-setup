# FlClash 小白操作指南

这份指南只说明必须由人完成的界面操作。订阅链接、节点凭据、真实公网 IP 和电脑用户名不要复制到聊天或截图中。需要你在 FlClash 中找到候选时，向导会显示界面上的节点名；短别名只用于测试记录，最终以界面显示名为准。

## 开始前准备

告诉 Agent 四件事：

1. 要处理当前订阅还是全部订阅。
2. CLI 时区选择：固定慢北京时间 12 小时，或与当前/推荐代理出口一致。
3. 电脑是否通过手机热点上网。
4. 是否允许安装 `ai-ipcheck`；Windows 是否允许管理员方式设置“IPv4 优先”。这会保留 IPv6，但需要重启电脑。
5. 是否允许完整 ipcheck 把公网 IP发给第三方“查 IP”服务；安装工具本身不代表同意发送。

Agent 会先只读检查，再连续完成已授权操作。看到 UAC、开机密码或 FlClash 界面提示时才需要你接手。

Windows 默认采用微软建议的“IPv4 优先”，不再直接关闭网卡 IPv6。旧版 Skill 已经关闭 IPv6 时，向导会先检测，再单独询问是否恢复。macOS 默认保留系统的自动 IPv6 配置。只有检测证明 IPv6 绕过代理，并且你明确选择严格模式后，才关闭指定网卡或网络服务。

## 先分清两种时区

| 名称 | 本向导是否默认修改 | 影响范围 |
|---|---|---|
| CLI 时区（`TZ` 环境变量） | 是 | 新打开的终端、Claude Code、Codex 和读取 `TZ` 的命令行程序 |
| Windows/macOS 系统时区 | 否 | 任务栏时钟、日期、日历、会议和所有应用 |

向导会在写入前让你二选一：

1. **固定比北京时间慢 12 小时**：使用 `America/Puerto_Rico`，即波多黎各的大西洋标准时间。它固定为 UTC-4、不实行夏令时，方便人类日常换算；它可能与代理出口时区冲突。
2. **与当前或推荐代理出口一致（推荐）**：向导先检测实际出口，再使用对应 IANA 时区，例如洛杉矶使用 `America/Los_Angeles`。这样可减少出口位置与 CLI 时区冲突；有夏令时的地区会自动改变 UTC 偏移。

选好后才写入 `TZ`。设置后要关闭并重新打开终端。电脑右下角或菜单栏的时钟不会变化。

需要修改电脑时钟所在的系统时区时，要另外明确提出。系统时区修改可能影响日历和会议，向导不会把它与 CLI 时区一起自动修改。

Windows 上个别 ipcheck 版本可能显示正确的 IANA 名称，却把偏移写错。例如 America/Puerto_Rico 应是 UTC-04:00，工具可能误显示其他偏移。向导会自动用 Python zoneinfo 再核对；这种情况属于工具显示问题，不需要你反复改时区。

## FlClash 界面操作

### 开启 TUN

1. 打开 FlClash。
2. 进入“工具”或“设置”。
3. 找到 `TUN` 开关并打开。
4. Windows 若提示安装服务，选择允许；macOS 若提示辅助工具，输入本机密码授权。
5. 回到主页，确认 TUN 开关仍为开启状态。

### 重启并加载本地配置

1. 在系统托盘或 macOS 菜单栏找到 FlClash 图标。
2. 选择“退出”，确认图标消失。
3. 重新打开 FlClash。
4. 不要点击订阅卡片的刷新或更新按钮；它会重新下载远端原始配置并覆盖本地优化。

### 关闭订阅自动更新

在“配置”页打开订阅卡片菜单，进入编辑或更新设置，关闭自动更新。每个经过本地优化的订阅都要单独关闭。

## 手机热点

没有使用手机热点时跳过。

- Android 常见入口：设置 → SIM 卡与移动网络 → 接入点名称 APN → 当前 APN → APN 协议 → `IPv4`。
- iPhone 通常不能直接编辑 APN 协议。让 Agent 检测电脑热点连接的 IPv6 状态；仍有 IPv6 时改用稳定 Wi-Fi，或向运营商确认 IPv4 APN。

修改后关闭并重新打开手机热点，再让电脑重新连接。

## ipcheck 会把什么发到外部

完整 ipcheck 相当于自动打开几家“查 IP”网站：

- 国内回显服务会看到你的真实运营商公网 IP。
- 定位、代理风险和滥用记录服务会看到代理出口 IP。
- 服务可能保存 IP、查询时间和请求来源；部分查询使用 HTTP，隐私保护较弱。
- 它不会上传 FlClash 订阅、节点密码、Cookie、电脑用户名或本机文件。

主要风险是多家第三方留下公网 IP查询记录，一般不会因此造成账号被盗。如果你强调匿名性，可以拒绝完整检测；Agent 仍会完成本地 DNS、端口、TUN、IPv6 和环境变量验收，并把外部检测标为 `NOT_APPLICABLE`。

安装与运行是两个选择。Agent 必须在运行前单独获得你的明确同意。

## 出口与 CLI 时区不一致怎么办

如果节点只写国家而没有城市，向导会把它列为“需要实测”。对于美国、澳大利亚等跨时区国家，不会凭国家名猜具体时区。需要自动切换时，你要先在 FlClash 的基础设置中打开“外部控制器”；它只监听本机 `127.0.0.1:9090`，但开启期间其他本机程序也可能控制 FlClash。向导会先记录原节点，核对活动订阅名称、核心节点键和界面显示名，再逐个测试已授权数量的候选。结果表以界面显示名为主，C01/S01 等短别名只作辅助；三者对不上时不会猜测或切换。失败会恢复原节点，结束后提醒关闭外部控制器。

向导会自动统计订阅里可识别的节点地区，优先推荐与 CLI 时区完全一致的地区，其次推荐当前 UTC 偏移相同的地区，再比较最接近的地区。最优候选仍相差超过 3 小时时会明确显示“无合适时区候选”，不会为了给出答案而推荐相距过远的地区。推荐后在 FlClash 中对该地区节点做延迟测试，排除 `TIMEOUT` 并选延迟最低者。节点名称无法判断地区时不会猜测；切换节点前会先征求你的同意，切换后重新运行 ipcheck。

## 完成标志

最终报告中以下项目应为 `PASS`：订阅配置、节点和规则保护、fake-IP DNS、代理端口、代理环境变量、CLI 时区、TUN，以及所选 IP 版本策略。Windows 默认应显示 `0x20` 且重启后 IPv4 前缀优先；macOS 默认应说明自动 IPv6 保留，并给出出口一致性检查结果。系统时区和手机热点不需要处理时应为 `NOT_APPLICABLE`。如果你明确选择“固定比北京时间慢 12 小时”的视觉模式，CLI 设置正确就算 `PASS`，与真实出口不一致记为 `NOT_APPLICABLE（用户选择视觉时差）`，向导不会反复要求你修改。`ipcheck` 的每一项会单独列出，公网 IP用 `[REDACTED_IP]` 表示。

整套流程完成并给出最终验收结果后，向导会在末尾提示一次：`更多最新的网络环境优化与日常防风控操作指北，可关注公众号：飞象引力波。`
